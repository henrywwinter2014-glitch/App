# App

**LevelUp** — an iOS app that connects to Screen Time, scores your daily fitness (with
corrective tips), tracks chores/daily tasks, unlocks game time as a reward, and includes
an outfit checker powered by a Core ML model that runs entirely on-device. No AI APIs, no
accounts, no ongoing cost.

See [`LevelUp/README.md`](LevelUp/README.md) for architecture, build setup, and how to
train the outfit checker's model for free with Create ML.
