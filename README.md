# App

**LevelUp** — an iOS app that connects to Screen Time, scores your daily fitness (with
corrective tips), tracks chores/daily tasks, unlocks game time as a reward, and layers in
Claude-powered features: a motivational coach chat, AI chore suggestions, weekly fitness
insights, a real-time game-time tip, and an AI outfit maker/scorer.

See [`LevelUp/README.md`](LevelUp/README.md) for architecture and build setup.
